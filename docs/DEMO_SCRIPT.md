# ChongmingBird Agent 3 分钟课堂演示讲解稿

## 0:00-0:30 开场

各位老师同学好，这是“重明鸟 ChongmingBird Agent”的 v0.3 事实核查演示原型。它不是普通聊天机器人，也不是训练新模型，而是一个面向新闻事实核查教学的可解释 Agent：大模型负责拆解、规划和分析，我们自己的程序负责检索、读取、保存 source、评分和课堂日志。

## 0:30-1:10 输入样例并启动

在输入框中粘贴示例：

> 网传某地因为食品安全问题关闭了所有中小学食堂。

保持“Demo 模式”勾选。Demo 模式不需要 DeepSeek 或 Tavily API Key，会使用固定 mock 数据，所以课堂现场即使没有网络密钥也能演示完整流程。点击“开始核查”。

## 1:10-1:50 观察 Agent Trace

请看“实时过程区”。系统会依次展示：正在拆解事实主张、生成搜索词、搜索网页、读取正文、分析证据关系、计算可靠性评分。这个区域的教学价值在于让学生看到事实核查不是直接问 AI 要答案，而是拆解主张、寻找证据、保留过程。

## 1:50-2:25 讲解证据卡片

接着看“证据区”。每张 Evidence Card 都保留标题、URL、来源类型、与主张关系、证据强度、摘录和理由。这里可以引导学生比较：哪些证据支持“存在个别食堂整改”，哪些证据反驳“所有中小学食堂关闭”。

## 2:25-2:50 讲解最终报告和评分

最终报告不是简单给“真/假”，而是给可靠性等级、分数、支持证据、反驳证据、不确定点、source 列表和仍需人工确认的问题。评分由独立 rubric 规则计算，不让模型随意打分。

## 2:50-3:00 人工裁决与课堂日志

最后，在“人工裁决区”选择是否接受 AI 结论，填写人工说明并保存。系统会写入 SQLite，后续可通过“导出课堂日志 CSV”用于课堂讨论和研究复盘。
